# Publication scope

This source-only copy preserves all 73 original Python files, the renderer bundle and GLB model byte-for-byte. Publication additions are documentation, roadmap/tracking files, templates, dependencies and ignore rules. Earlier prototype versions are retained intentionally.

Personal screen captures, runtime JSONL logs, local editor state, virtual environments, compiled caches, scientific datasets and generated results are excluded. See `data/README.md` for the scientific-data setup gap.

Syntax validation is not an end-to-end simulation test. No OBS connection, screen capture, external AI request or full simulation was run during publication preparation. Known credential and personal-machine-path patterns were checked in the sharing copy. Review any future generated files before sharing them.
